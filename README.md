I'm a Backend Software Engineer based in Ho Chi Minh City, with nearly 2 years of experience building services in **Java** and **Spring Boot**.

- 💼 Software Engineer at **WALA_ICT** since Jul 2025, working on multi-tenant SaaS, AI content pipelines and microservice deployments
- 🧱 I care about data integrity: schemas and constraints that keep data consistent at the database level
